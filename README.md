# SolarIQ website

A responsive, static website for the SolarIQ venture. The content is based on the venture presentation and keeps prototype work separate from features that are still being developed.

## Run locally

1. Open this folder in Visual Studio Code.
2. Open `index.html`.
3. If the Live Server extension is installed, select **Open with Live Server**.
4. Or open `index.html` directly in a browser.

No build step or package installation is required.

## Publish

Upload the complete `SolarIQ-Website` folder to a static host such as Netlify, GitHub Pages or Vercel. Keep `index.html`, `styles.css` and `script.js` together.

## Before publishing

- Add the venture's official email address or enquiry form destination to the contact section.
- Replace the illustrative solar visuals with approved photographs of the actual prototype when available.
- Add official team details and social links only after they are confirmed.
- Publish performance figures only after testing and verification.
- The website describes SolarIQ as a product under development; do not imply unverified performance or deployed cloud features.

## Project files

- `index.html` — website content and brand mark
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation and footer year

The website uses plain HTML, CSS and JavaScript. No backend, API keys, database or framework is required.
